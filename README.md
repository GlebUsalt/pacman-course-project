# Игра Pac-Man на C (курсовая работа, «Структуры данных»)

Курсовая работа по дисциплине «Структуры данных», Институт компьютерных наук и кибербезопасности, СПбПУ Петра Великого, 2026 год. Реализация классической аркады Pac-Man на языке C с рендерингом через OpenGL.

Курсовая работа выполнена в составе пары: Усольцев Г. В., Тусюк М. К.

## Описание игры

Пакмен перемещается по лабиринту (сетка 23×21 клетка), собирает точки и энерджайзеры, избегая столкновения с четырьмя призраками. При поедании энерджайзера призраки на ограниченное время переходят в испуганное состояние и могут быть уничтожены. У игрока три жизни, текущий рекорд сохраняется в файл `highscores.txt`. Игра имеет главное меню (START GAME, HELP, ABOUT, EXIT) и состояния победы/поражения с перезапуском.

## Технологии

- Язык: C
- Рендеринг: OpenGL (GLEW, GLFW)
- Среда сборки: Visual Studio (MSBuild, `.vcxproj` / `.sln`)

## Ключевые алгоритмические решения

- **Лабиринт** представлен статической сеткой, генерируется последовательным заполнением массива по контуру, с отдельным построением зоны появления призраков, порталов и энерджайзеров.
- **Движение Пакмена** дискретно по игровым тикам (`PAC_SPEED`), направление задаётся буферизованной парой `(nextDX, nextDY)` для отзывчивого управления с клавиатуры.
- **Логика призраков** основана на манхэттенском расстоянии до Пакмена: в обычном режиме призрак минимизирует расстояние (преследование), в испуганном режиме, после поедания энерджайзера, максимизирует его (бегство). Решение выбрано вместо поиска кратчайшего пути (BFS/A*) ради вычислительной простоты O(1) на шаг при четырёх призраках, работающих в реальном времени, и предсказуемости поведения для игрока. Разворот на 180° запрещён отдельной проверкой, чтобы призраки не застревали в узких коридорах.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.c` | точка входа, главный игровой цикл |
| `game.c` / `game.h` | игровая логика: лабиринт, движение, столкновения, счёт |
| `render.c` / `render.h` | отрисовка через OpenGL |
| `menu.c` / `menu.h` | главное меню и переходы между состояниями игры |
| `highscores.c` / `highscores.h` | чтение и запись таблицы рекордов |
| `constants.h` | константы игры (размеры сетки, скорости, тайминги) |

## Сборка

Проект собирается в Visual Studio через `Course_project_PACMAN.sln`. Для сборки нужны библиотеки GLEW 2.3.1 и GLFW 3.4: пути к ним заданы в свойствах проекта (`IncludePath` / `LibraryPath`) и при сборке на другой машине их нужно указать заново под расположение библиотек в своей системе.
